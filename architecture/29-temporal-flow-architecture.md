## 1. Overview

**The Temporal Flow** is a living, infinite-canvas map of your software architecture that visualizes codebase evolution, system health, and dependency risks in real-time. It transforms static diagrams into a dynamic, scrubbable temporal graph highlighting technical debt, active churn, and PR blast radiuses over time.

Designed for Staff Engineers, Engineering Managers, and Systems Architects, it addresses the need to understand system health historically, track ownership gaps, and predict the impact of architectural changes safely.

## 2. Core Concepts

The Temporal Flow leverages the `ArchitectureSnapshot` data already generated by the system. It builds upon it by adding:
- **Time-Series Interpolation:** Smooth transitions between node/edge states across snapshots.
- **Heatmapping:** Visual overlays for activity (commits, PRs), risk (blast radius), and health (tech debt).
- **Hierarchical Edge Bundling:** Managing visual complexity when viewing macro systems.

## 3. Component Breakdown

### 3.1 Macro System View
- High-level infinite canvas showing all microservices/modules.
- Uses **Hierarchical Edge Bundling** to group related dependencies, preventing visual clutter ("hairball" effect).
- Overlays health heatmaps based on metrics computed in the metrics pipeline.

### 3.2 Component Deep Dive
- Expanded side-panel focusing on a single node (file/module).
- Displays chronologic activity (who edited it, when).
- Tracks ownership changes and highlights ownership gaps.
- Shows historical PR impact specific to this component.

### 3.3 Dependency Risk Flow
- Targeted view for specific analysis.
- Highlights glowing blast-radius paths dynamically when simulating historical or current changes.
- Identifies critical architectural bottlenecks and central points of failure.

### 3.4 Temporal Playback
- Time-machine mode with a bottom scrubber.
- Animates the codebase's evolution over weeks or months.
- Nodes appear, disappear, or change size/color based on metrics at the specific snapshot time.

## 4. Data Model Implications

This feature mostly consumes existing data models but may require optimizations:
- Fast retrieval of time-series metric data for nodes.
- Caching of delta graphs (differences between snapshot N and N+1) to ensure UI performance during playback.

## 5. Implementation Strategy

This feature represents a major enhancement to the visualization capabilities and will be implemented as **Milestone 13**.
- **Phase 1:** Core playback scrubber and timeline API.
- **Phase 2:** Canvas rendering optimizations (edge bundling, WebGL if React Flow performance limits are hit).
- **Phase 3:** Deep dive panels and risk flow visualizations.
