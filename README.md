# SystemMapper

SystemMapper is an advanced, automated architectural visualization tool that helps developers instantly understand complex codebases.

## ✨ What you can do with SystemMapper

- **Scan GitHub Repositories**: Connect to public or private repositories and trigger automated ingestion.
- **Visualize Architecture**: Automatically generate a highly interactive node-based graph of your system.
- **Understand Dependencies**: See exactly how files, functions, and classes relate to each other without manually reading the code.
- **Intelligent Filtering**: Automatically ignores non-essential files (like `node_modules`, `.next`, `dist`, `.turbo`) so you only see the core architecture that matters.
- **Explore Codebases**: Zoom, pan, and click on nodes in the UI to explore large, complex codebases visually.
